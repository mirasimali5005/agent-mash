Chats you started in a desktop app

Your app chats are the same chats as on the website, because they sync to your account. Two ways to add one:

• Open the chat on the website once and click the bookmark.
• Or press ⌘A ⌘C inside the app's conversation, then click Add here and paste it into Conversation text, plus the link.

Other ways

App link formats

{url} is the full link, {path} is the part after the domain, and {id} is the last part. Leave a format as {url} to open the website. On iPhone, iPad and Android, chats always open the website link, which the installed app takes over automatically.

Understand chats automatically optional

With a Claude API key, Agent Mash reads the conversation text you capture and writes a title, summary, tags, search keywords and a folder for you. In search, Ask Claude also finds chats by meaning, not just exact words.

Without a key, it still picks keywords and suggests a folder on its own, right in your browser.

Get one at console.anthropic.com. It's stored only in this browser and sent only to api.anthropic.com. Pages hosted under the same *.github.io address can read this browser storage, so use a key with a low spend limit.

Your data never leaves this browser

Agent Mash is a private library, not a service. It has no account, no server, no analytics and no cookies. You decide which conversations to keep, and they're stored on this device.

What stays here

Your chats, folders, tags, notes, captured conversation text and settings are kept in this browser's local storage. Clearing this site's data in the browser removes them, so keep a backup.

The only things that ever go over the network

• The app itself. GitHub Pages sends the page files once. It never receives your chats.
• Opening a chat. Your browser goes to that AI's website or app, just like clicking a bookmark.
• Claude AI, only if you turn it on. When you analyze a chat or use Ask Claude, that chat's text goes to api.anthropic.com, and the Claude SDK loads from cdn.jsdelivr.net. Without a key, neither happens.

Start over

Remove everything Agent Mash has stored in this browser. Download a backup first if you might want it back.

Back up your library

Your library lives only in this browser, so a backup is the copy you keep. It's a plain JSON file you can store anywhere (iCloud Drive, Dropbox, a USB stick) and restore here or on another device. Your API key is never included.

Restoring adds chats you don't have yet. Nothing is overwritten. You can also drop a backup file onto the window.
