Save to Agent Mash

Then, on any ChatGPT, Claude or Gemini chat, click it. The button copies the chat's link, title and conversation text to your clipboard and opens Agent Mash. Press ⌘V there to bring it in. Nothing from the conversation is ever put in a web address, so it can't end up in your browser history. Agent Mash clears it from the clipboard once it's pasted.

Why there are no custom app links

Desktop-app links are built only from the verified list above, and only from a valid https:// chat link. Custom link formats were removed because they could be used to launch arbitrary apps or scripts. On iPhone, iPad and Android, chats open the website link, which the installed app takes over automatically.

Understand chats automatically optional

With a Claude API key, Agent Mash can read a chat's saved conversation text, when you click “Fill in with Claude”, and write a title, summary, tags, search keywords and a folder for you. Nothing is sent automatically. In search, Ask Claude also finds chats by meaning, not just exact words.

Without a key, it still picks keywords and suggests a folder on its own, right in your browser.

Kept in memory only. The key is never saved to this browser, never put in backups and never in a link, so you'll enter it again after you reload or close Agent Mash. It's sent only to api.anthropic.com. Calling the API from a browser is less safe than calling it from a server, so use a key with a low spend limit that you can revoke. Get one at console.anthropic.com.

Your data never leaves this browser

Agent Mash is a private library, not a service. It has no account, no server, no analytics and no cookies. You decide which conversations to keep, and they're stored on this device.

What stays here

Your chats, folders, tags, notes, captured conversation text and settings are kept in this browser's local storage. Clearing this site's data in the browser removes them, so keep a backup.

The only things that ever go over the network

• The app itself. GitHub Pages sends the page files once. It never receives your chats.
• Opening a chat. Your browser goes to that AI's website or app, just like clicking a bookmark.
• Claude AI, only if you turn it on. When you analyze a chat or use Ask Claude, that chat's text goes to api.anthropic.com, and the Claude SDK loads from cdn.jsdelivr.net. Without a key, neither happens.

Start over

Remove everything Agent Mash has stored in this browser. Download a backup first if you might want it back.

Back up your library

Your library lives only in this browser, so a backup is the copy you keep. It's a plain JSON file you can store anywhere (iCloud Drive, Dropbox, a USB stick) and restore here or on another device. Your API key is never included.

Restoring adds chats you don't have yet. Nothing is overwritten. You can also drop a backup file onto the window.

Backups and exports are not encrypted. They contain your saved conversation text in plain form, so keep them somewhere private and don't share them.

Export for notes apps

Take your library into Obsidian, Logseq, Apple Notes or any Markdown editor. Each chat becomes a note with its link, summary, tags, your notes and the captured conversation.

The vault keeps your folders, uses YAML front matter Obsidian understands, and includes an index note that links every chat. Markdown is for reading. To restore your library, use the JSON backup above.
